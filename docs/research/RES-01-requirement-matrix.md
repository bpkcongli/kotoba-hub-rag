# RES-01 — Matriks requirement–metric–artifact

Tanggal: 23 November 2026. Acuan: [PRD](../../PRD.md), [protokol v1](RES-01-protocol.md), dan [CON-01](../contracts/CON-01.md). Cakupan: **FR-01–14 dan NFR-01–08, 22 requirement unik**.

Semua path `artifacts/<run_id>/...` pada tabel adalah **artefak rencana yang belum dihasilkan**. Bukti yang tersedia saat RES-01 hanya dokumen planning, JSON plan/template, source manifest dan verifikasi offline; hasil CON-01 adalah bukti kontrak dengan mock. Matriks ini tidak menyatakan runtime, dataset, provider, judge atau main experiment sudah lolos.

Definisi unit: **parent** = case×mode×repetition, main 1.800 outcomes (600/mode); **child** = request operasi, termasuk normalize/recommend; **call** = actual provider attempt. Coverage/missing/N/A wajib dilaporkan per metrik. Gagal tetap masuk seluruh scheduled-parent denominator untuk reliability. Applicability dan primary-eligible subset ditentukan dari label/rubric sebelum main, tidak dipilih dari hasil.

Metrik konfirmatori Q dan batas draf TA 3.10.6 merangkum FR-07/08/09 serta NFR-07, tetapi tidak menggantikan requirement lain. Routing macro-F1 dan escalation, schema/error rate, aspek kritis serta hard-retrieval endpoint tetap gate keseluruhan. Model version, primary rubric, missing policy dan denominator yang berubah setelah freeze memerlukan cohort/protocol baru.

Readiness RES-01 adalah traceability desain. Semua baris bertanda future task memerlukan evidence aktual; tidak boleh mencentang task runtime hanya karena matriks ini memuat nama artefaknya.
